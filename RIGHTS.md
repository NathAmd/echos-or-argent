# Droits et contributions

Le nom public de cette alpha est **Échos d’Or & d’Argent**. « PokeMaster » reste
un identifiant technique historique dans les formats de sauvegarde et le code.

Aucune licence libre générale n'est accordée à ce stade au code propre du
projet. Les droits restent à leurs titulaires ; les autorisations impératives
prévues par la loi et les conditions de la plateforme restent applicables.
Un dépôt visible sur GitHub ne suffit pas à autoriser toute réutilisation.
Le choix d'une licence pourra être fait par les titulaires après vérification
de la provenance du code. Ne pas apposer une licence MIT globale par défaut.

Les licences existantes des dépendances et ressources tierces continuent
de s'appliquer. Le build Vite produit `THIRD_PARTY_LICENSES.md` pour les
bibliothèques distribuées. Les trois SVG `menu-button.svg`,
`menu-button-selected.svg` et `ornate-panel.svg` portent déjà une déclaration
CC0-1.0 dans leurs métadonnées ; elle est conservée.

Les textures abstraites de `web/public/ui/themes/` sont décrites comme
originales dans le code existant. Cette description et leur inspection
visuelle ne constituent pas une preuve de provenance : conserver leurs
fichiers de création et vérifier les droits avant diffusion.

Le favicon géométrique et ses déclinaisons PNG ont été créés pour cette
préparation. Aucun emblème de jeu n'y est incorporé.

Le code cite notamment `pret/pokeheartgold` comme référence de comportement.
La disponibilité publique d'une décompilation n'autorise pas automatiquement
la redistribution de son code. Avant publication, vérifier que les portions
concernées sont des implémentations propres, ou disposer des autorisations
et attributions nécessaires. Ce travail n'a pas certifié cette provenance.

Ne jamais ajouter ROM, BIOS, extractions, captures de jeu, sauvegardes,
clés, jetons ou références privées au dépôt. Les exemples de tests doivent
être synthétiques ou accompagnés d'une autorisation explicite.
